# CRM «Атланта»

Современная CRM-система для производственных и торговых компаний. Включает управление клиентами, заказами, коммерческими предложениями, каталогом компонентов (BOM) с модификациями и документами, базой чертежей, калькулятор спецификаций, каталог оборудования производителей, уровни ценообразования, отчётность с экспортом в Excel/PDF и гибкую ролевую модель доступа (RBAC).

---

## 🚀 Возможности системы

### Основные модули

* **📊 Аналитический дашборд** — ключевые KPI (выручка, маржинальность, комиссия агента), графики динамики заказов (столбчатые и кольцевые), дашборд руководителя, топ клиентов.
* **📦 Управление заказами** — расчёт комиссий принципала, спецификации позиций с наценками (поуровневые + ручные), степперы ±, добавление из каталога компонентов и чертежей, экспорт и статусы.
* **📝 Коммерческие предложения (КП)** — формирование КП для клиентов с позициями из каталога, наценки уровней, статусы, сроки действия, экспорт.
* **👥 База клиентов** — карточка клиента с таймлайном событий (звонки, встречи, оплаты), загрузка документов, история чертежей, контакты, пользовательские статусы, присвоение уровня ценообразования.
* **🧮 Калькулятор чертежей** — расчёт спецификаций компонентов (BOM) с наценками (%, ₽), сохранение в базу чертежей, перевод в заказ, скачивание сертификатов и документов компонентов (ZIP).
* **📐 Каталог чертежей** — база рассчитанных чертежей с группировкой по клиентам, просмотром состава компонентов и статусов.
* **🔩 Каталог компонентов** — фото, артикулы, цены, категории, модификации с фото, два режима отображения (витрина / таблица), прикрепление сертификатов и информационных документов (PDF/JPEG/PNG).
* **🏭 Каталог производителей и оборудования** — база производителей с контактами и реквизитами, номенклатура оборудования с типами, привязкой к чертежам и ценообразованием.
* **💰 Уровни ценообразования** — настраиваемые уровни наценок (Дилер, Розница и т.д.) с привязкой к клиентам, автоматическое применение наценки при формировании заказов и КП.
* **📈 Отчёты и аналитика** — срезы по заказам, клиентам, принципалам, выгрузка в Excel (`.xlsx`) и PDF с корректной кириллицей.

### Системные функции

* **🛡️ RBAC** — ролевая модель с интерактивной матрицей прав по 8 разделам (просмотр / редактирование / удаление / экспорт).
* **👤 Управление пользователями** — создание, редактирование, назначение ролей с гранулярными правами.
* **💲 Настройка НДС** — отображение цен с выделением НДС (настраиваемая ставка и переключатель).
* **📎 Документы компонентов** — загрузка сертификатов и информационных сообщений (PDF/JPG/PNG), скачивание ZIP-архивом из заказов и калькулятора.
* **🌓 Тёмная / светлая тема** — переключение с сохранением в localStorage.

## 🛠️ Стек технологий

| Слой | Технологии |
|------|-----------|

## 📦 Быстрый старт

### Вариант 1: Docker Compose (рекомендуется)

```bash
git clone https://github.com/alexeychekalin/AtlantaCRM-deploy.git
cd AtlantaCRM-deploy
docker-compose up -d --build

# Инициализация тестовых данных (первый запуск)
docker-compose exec app node server/src/db/seed.js
```

Откройте: `http://localhost:3000`

### Вариант 2: Локальный запуск (Node.js + PostgreSQL)

```bash
# 1. Установить зависимости
npm run postinstall

# 2. Настроить подключение к БД
cp .env.example server/.env
# Отредактируйте DATABASE_URL, JWT_SECRET в server/.env

# 3. Применить схему БД и миграции
npm run db:init

# 4. Запустить
npm run dev       # режим разработки
npm start         # продакшн
```

Откройте: `http://localhost:3000`

## 🗄️ Миграции БД

При обновлении выполните все файлы `migration_*.sql` из `server/src/db/`:

```bash
psql -h <host> -U <user> -d <db> -f server/src/db/schema.sql
psql -h <host> -U <user> -d <db> -f server/src/db/migration_components.sql
psql -h <host> -U <user> -d <db> -f server/src/db/migration_client_profile.sql
psql -h <host> -U <user> -d <db> -f server/src/db/migration_client_status.sql
psql -h <host> -U <user> -d <db> -f server/src/db/migration_order_metadata.sql
psql -h <host> -U <user> -d <db> -f server/src/db/migration_order_components.sql
psql -h <host> -U <user> -d <db> -f server/src/db/migration_delivery_invoices.sql
psql -h <host> -U <user> -d <db> -f server/src/db/migration_equipment.sql
psql -h <host> -U <user> -d <db> -f server/src/db/migration_pricing_levels.sql
psql -h <host> -U <user> -d <db> -f server/src/db/migration_component_documents.sql
```

Все миграции используют `IF NOT EXISTS` — безопасны для повторного запуска.

## 📡 API-маршруты

| Модуль | Эндпоинт | Описание |
|--------|----------|----------|
| Авторизация | `/api/auth` | Логин, проверка токена |
| Клиенты | `/api/clients` | CRUD, поиск, фильтрация |
| Профиль клиента | `/api/clients/:id/timeline`, `contacts`, `documents` | Таймлайн, контакты, документы |
| Статусы клиентов | `/api/client-statuses` | Пользовательские статусы |
| Заказы | `/api/orders` | CRUD, экспорт Excel/PDF |
| КП | `/api/proposals` | CRUD, экспорт |
| Компоненты | `/api/components` | Каталог, поиск, фильтры |
| Модификации | `/api/components/:id/modifications` | CRUD модификаций |
| Документы компонентов | `/api/components/:id/documents` | Сертификаты, инфо, ZIP-скачивание |
| Категории | `/api/component-categories` | CRUD категорий |
| Чертежи | `/api/drawings` | CRUD, привязка компонентов |
| Принципалы | `/api/principals` | Агенты-принципалы |
| Производители | `/api/manufacturers` | CRUD производителей |
| Оборудование | `/api/manufacturer-products` | Номенклатура оборудования |
| Типы оборудования | `/api/equipment-types` | Справочник типов |
| Уровни цен | `/api/pricing-levels` | Настройка наценок |
| Отчёты | `/api/reports` | Аналитические срезы |
| Дашборд | `/api/dashboard` | KPI, графики |
| Загрузка файлов | `/api/upload` | Изображения, чертежи, документы |
| ZIP-документы | `/api/component-documents/download-zip` | Массовое скачивание |
| Роли | `/api/roles` | RBAC матрица прав |
| Пользователи | `/api/users` | Управление пользователями |
| Настройки | `/api/settings` | НДС, системные настройки |
