# Разбор PDF-каталога

Скрипты готовят фрагменты `server/src/db/catalog/catalog.json` из каталога АТЛАНТА-26.
Сам PDF в репозиторий не кладётся — он нужен только на время разбора.

```bash
pip install --break-system-packages pypdf pymupdf
python3 scripts/catalog/build_marker.py "/путь/Каталог АТЛАНТА-26.pdf" /tmp/out
```

На выходе `/tmp/out/<раздел>.json` и `/tmp/out/files/*` — фрагмент и фото.
Дальше фрагмент просматривается глазами (названия, привязка фото, коды) и
вливается в `catalog.json`; импорт в базу — `npm run db:catalog`.

| Скрипт | Раздел | Стр. |
|---|---|---|
| `build_marker.py` | Фонари габаритные (бортовые огни) | 19–46 |
| `build_lights.py` | Указатели поворота + фонари освещения номера | 48, 50–54 |
| `build_harness.py` | Электропровода (жгуты) | 68–73 |

Особенности каталога, которые уже учтены:

- код модификации обычно в скобках после артикула, но бывает и в середине —
  `А.3731.010 (03.04)-Т`, `А.3731.018-41 (03)-У`;
- описания в таблицах переносятся на 2–4 строки, строки «артикул + код»
  и «описание» разделены;
- у части семейств страница с фото и характеристиками отделена от страницы
  с таблицей артикулов (стр. 26/27, 41/42, 43/44);
- фото привязывается по индексу только когда число фото совпадает с числом
  артикулов на странице, иначе одно фото отдаётся всему семейству с пометкой
  в описании;
- в разделе ФОНЗ фото стоит **ниже** таблицы, поэтому выбирается по минимальной
  `y0` (фото всегда выше чертежа), с отбраковкой `w < 300`, `h >= 1100`,
  `w/h <= 0.5` — так отсекаются логотипы сертификатов;
- в разделе жгутов на странице несколько подтаблиц: заголовок «А.3724.* ЖГУТ …»
  и пометка «(РОЗЕТКА-ВИЛКА)» — отдельные блоки, пометка своя у каждой
  подтаблицы; артикул сразу полный, модификаций нет;
- в жгутах описание и фото стоят в блоке **выше** артикула, причём на разную
  высоту, поэтому они привязываются к ближайшему артикулу по центру блока
  (±70 pt), а не «следующему по порядку»;
- на стр. 70–72 каталога колонка «ФОТО» пустая, на стр. 73 двум исполнениям
  (504-01 и 504-02) напечатано одно и то же фото — позиции импортируются
  без фото/с общим фото, заглушки не выдумываются.
